## 已复现并处理的问题

- 期限计时器 unref 导致 Node 在等待挂起操作时提早退出，测试被取消。
- 等待与取消窗口使用的超时 race 未清理计时器，容易留下未完成的期限。
- 隔离进程被取消时，页面关闭错误可能抢先覆盖取消结果。
- 取消测试依赖固定 sleep；改为监听 step-start 并执行取消。
- 浏览器默认关闭 TLS/CORS/CSP 检查的旧环境兼容选项改为显式启用。
