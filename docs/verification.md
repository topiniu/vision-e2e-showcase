## 已复现并处理的问题

- 期限计时器 unref 导致 Node 在等待挂起操作时提早退出，测试被取消。
- 等待与取消窗口使用的超时 race 未清理计时器，容易留下未完成的期限。
- 隔离进程被取消时，页面关闭错误可能抢先覆盖取消结果。
- 取消测试依赖固定 sleep；改为监听 step-start 并执行取消。
- 浏览器默认关闭 TLS/CORS/CSP 检查的旧环境兼容选项改为显式启用。

## 依赖审计

1.11.1 完整依赖树曾有 13 项告警（8 high、5 moderate）。1.11.2 将受影响的 minimatch 升级到 11.0.9，并为尚无上游修复版的 picomatch 引入可审查的本地安全分支；完整 npm audit 已为 0。

**npm audit 不覆盖本地分支。** 因此 CI 同时检查补丁文件 SHA-256、实际依赖解析路径和限时攻击样例，缺一不可。补丁阻止危险的重复 extglob 正则生成，包含嵌套量词、歧义字面量分支及忽略大小写后的分支重叠；这些模式改为字面量匹配。普通匹配、构建与目录打包经过回归。来源、兼容边界和维护方式见[依赖安全说明](dependency-security.md)。没有使用强制降级或审计忽略规则消除计数。

已更新 MCP SDK、Electron、Playwright 及 Zod；Zod 4 的 record schema 使用显式 key/value 类型。组件维护 CLI 通过 npx 按需使用，不作为应用的安装依赖；其原有静态样式原样保存在 vendor 目录，并附来源与许可证。
