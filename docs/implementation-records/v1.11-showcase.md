# v1.11 求职展示版

## 基本信息

- 日期：2026-11-18
- 基线：v1.11.0
- 状态：本地验收与公开前审查完成；按授权公开展示仓库

## 背景与目标

将桌面 E2E 平台整理为可独立运行、可审查的求职作品。公开候选版本使用新 Git 历史；原仓库和历史不迁入。

## 实施范围

- 只保留执行器、面板、通用协议、测试及必要的应用资源。
- 删除内部业务用例、登录状态、凭据、内部运维脚本、旧演示与聊天资料。
- 默认导航和示例改为本地演示；保留环境参数和外部凭据引用能力。
- 增加本地正反例演示、脱敏门禁、CI、README 与技术说明。
- 修复经复现确认的测试和运行时问题，不通过跳过测试达成全绿。

## 验证记录

当前 1.11.3 完整自动化回归 748/748 通过；正反例演示与证据校验、前端构建、工作树及完整历史脱敏、文档链接检查通过。干净安装后，全依赖 npm audit 为 0，并额外通过本地 picomatch 分支的文件完整性、实际加载路径与限时漏洞回归检查。目录包和托管平台历史清理结果按实际完成情况记录到验证记录；CI 对应提交结果见 Actions。展示仓库按独立授权公开，原私库及旧展示归档保持私有。
